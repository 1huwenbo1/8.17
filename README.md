# 豫见华夏 · 河南文物互动之旅

一个以河南代表性文物为线索的桌面端互动网页。访客可按年代顺序探索贾湖骨笛、妇好鸮尊、亚长牛尊、玉柄铁剑与莲鹤方壶，并体验文物图鉴、文明印记、文创展示、背景音乐和页面转场。

## 在线访问

发布后通过 GitHub Pages 访问。

## 本地预览

直接用现代浏览器打开 `index.html`。首次进入时点击“开启声音”或“静音探索”，即可开始体验。

## 项目结构

- `index.html`：页面结构
- `styles.css`：视觉样式与动画
- `app.js`：交互、音频及页面状态
- `assets/`：网页使用的 WebP 图片、音频和缩略图数据
